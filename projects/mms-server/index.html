MMS Server

An android application that handles all the operations for sending dollars and days to touch and alfa mobile numbers from the MMService application.

What it taught me

Working close to the Android platform: listening for incoming SMS and USSD responses, sending from two SIM cards and keeping data in sync between SQLite and Firestore.

Tech

Worked on implementing the required listeners for reading and processing incoming messages and USSD messages.

Worked on the implementation for sending messages from both Sim 1 and 2 programmatically using the SmsManager and running USSD codes.

Used SQLite and Firebase Cloud Firestore for saving and reading data.
